## Rules

- `Match status` should be one of: `matched`, `weak-match`, `manual-review`, `not-found`
- `Resolver` should record the actual source used, usually `semantic-scholar`
- Use `unknown` for any unresolved field
- Do not replace manual review with automatic confidence claims
